# contact_management
practice project to build a contact management system.
Command to install node_modules: npm i.
The following files need to be created at the root level of the project folder: .gitignore and .env
The content of .env file is as follows:
// Server port
PORT=3000

// Database connection
DB_PORT = <YOUR_PORT>
DB_HOST = localhost
DB_USERNAME = <USER_NAME>
DB_PASSWORD = <PASSWORD>
DB_NAME = contact_management
